How Project Risk Predictions Work?

RIVEXA combines XGBoost algorithms with SHAP game theory values. When you input SDLC metrics (budget, cost overruns, timeline delays, velocity drift, and bug densities), the backend scales values and computes early-failure probability percentages with high confidence scoring.

How Model Retraining operates?

Analysts with high permissions can upload a CSV training set on the Models tab. The backend preprocesses the files, splits values, and runs parallel training across Random Forest and Gradient Boosting metrics, selecting the optimized best-F1 model for future predictions.
